# Blackjack-JS

A terminal-based blackjack game coded in JavaScript.

## Overview

Blackjack-JS is a command-line implementation of the popular card game Blackjack. The project is designed to recreate the traditional Blackjack experience within a terminal environment, featuring player-versus-dealer gameplay, card management, and standard Blackjack rules.

The project utilizes a modular structure to separate game logic, card management, and terminal display functionality.

## Features

- Standard Blackjack gameplay
- Automatic deck generation and shuffling
- Automatic deck replenishment
- Blackjack hand value calculations
- Dynamic Ace valuation (1 or 11)
- Terminal-based card rendering

## Installation

### Prerequisites

- Node.js
- Git

### Clone the repository

```bash
git clone https://github.com/leemo-jeemo/Blackjack-JS
cd Blackjack-JS
```

### Install dependencies

```bash
npm install
```

## Usage

Start the game from the project directory:

```bash
npm start
```

The game will launch directly in the terminal.

## Technologies

- **JavaScript** - Core programming language.
- **Node.JS** - JavaScript runtime environment.
- **ES Modules** - Modular code organization using import and export.
- **Node.js Readline** - Terminal input handling.
- **Chalk** - Terminal text styling and colors (planned).
- **Figlet** - ASCII text rendering (planned).
